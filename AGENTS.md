# Instrucciones del proyecto

## General
- Responde en español.
- Escribe código limpio y mantenible.
- Sigue las convenciones de Microsoft y .NET.
- No inventes funcionalidades ni dependencias.
- Explica brevemente los cambios realizados mediante comentarios.

## ASP.NET
- Respeta la arquitectura existente.
- Prioriza las buenas prácticas de C#.
- Utiliza inyección de dependencias.
- Evita duplicar código.
- Gestiona correctamente los errores.

## Seguridad
- Nunca expongas contraseñas ni API Keys.
- No guardes secretos en Git.
- Valida los datos recibidos.
- Aplica las buenas prácticas de seguridad web.

## Git
- No hagas commits sin autorización.
- No hagas push sin autorización.
- No sobrescribas cambios existentes.
