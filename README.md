### EJECUCIÓN DEL PROYECTO EN CASO DE NO TENER IDE

### INSTALAR SDK (NECESARIO)
1- Pulsar Win + 'X' y en el menú desplegable seleccionar "Terminal".  
2- Una vez dentro del termina ejecutar la siguiente instrucción:   
  winget install Microsoft.DotNet.SDK.10

### EJECUCIÓN DEL PROYECTO
1- Desde el terminal ejecutar la instrucción "cd _RutaDelProyecto_" para moveros a la carpeta donde se encuentre el Proyecto. Por ejemplo:  
  cd C:\Users\polgv\OneDrive\Escriptori\PersonalPrograms\HeroQuest  
2- Una vez dentro de la carpeta ejecutar la siguiente instrucción para abrirlo (la cuál instalasteis junto al SDK):  
  dotnet run
